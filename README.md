# Jayshakti Farsan Mart - Barcode Printer Setup

## Prerequisites
1. **Python**: Ensure Python 3.9+ is installed. During Windows installation, check **"Add Python to PATH"**.

## Setup on Windows PC (Shop)
1. Place this entire folder on the Desktop (or anywhere convenient).
2. Double-click `Start_Barcode_App.bat`.
3. The script will automatically install necessary dependencies (Streamlit, Pandas, Openpyxl, and PyWin32) and open the web app in your browser.

## Testing on macOS (Mac Mini)
1. Open Terminal and navigate to this folder.
2. Run `pip install -r requirements.txt`
3. Run `streamlit run app.py`
4. The app will launch at `http://localhost:8501`.

## Printer Configuration
- **Windows**: The app automatically uses the `win32print` module to send RAW commands. Make sure the TSC TTP-244 Plus printer is installed in Windows Settings -> Printers & Scanners. No BarTender software is required.
- **macOS**: The app uses the `lpr` command line utility to send RAW commands to CUPS. Ensure your printer is added in System Preferences -> Printers & Scanners.

## Using the App
1. Place the `Item_Details_Report.xlsx` file generated by the ezo billing machine inside this same folder.
2. Select an item from the dropdown. The app will auto-calculate Weight, MRP, Batch (MMDD), and Expiry Date (Date + 60 Days).
3. Select your connected printer from the dropdown on the right side.
4. Set the quantity (number of full 50x75 sheets) and click "Print Labels".
